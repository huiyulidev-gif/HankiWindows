# 한키 0.2.1-rc.1 알려진 제한

- 일반 권한으로 실행되므로 관리자 권한으로 실행된 프로그램의 입력창에는 접근하지 못할 수 있습니다.
- Windows 보안 화면, UAC 보안 데스크톱, 잠금 화면과 비밀번호 입력창에서는 동작하지 않습니다.
- UI Automation `TextPattern`을 제공하지 않는 프로그램에서는 안전을 위해 변환을 생략합니다.
- 일부 게임과 안티치트가 있는 환경에서는 키보드 훅 또는 주입이 차단될 수 있습니다.
- 일부 커스텀 에디터, 터미널, 원격 데스크톱은 지원하지 않거나 기본 제외되어 있습니다.
- Space·Enter·숫자패드 Enter·Tab을 처리하지만, Tab이 즉시 포커스를 옮기는 앱에서는 캐럿 문맥을 잃어 변환이 생략될 수 있습니다.
- 일부 한글 IME 또는 서드파티 IME 환경에서는 Space 이후 조합 완료 시점 차이로 변환이 생략될 수 있습니다.
- 관리자 프로그램 지원을 위해 한키 자체의 관리자 권한을 강제하지 않습니다.
- Chrome/Edge, 디스코드, 카카오톡은 각 버전과 접근성 구현에 따라 동작이 달라질 수 있으므로 실제 사용 환경에서 확인이 필요합니다.
- 코드 서명 인증서가 없어 SmartScreen 경고가 나타날 수 있습니다.
- Google 로그인은 별도 Supabase redirect 등록과 공개 설정 파일이 있어야 활성화됩니다.
- 로그인은 계정 연결만 제공하며 단축어 클라우드 동기화는 제공하지 않습니다.
- 고정 loopback 포트 43289를 다른 프로세스가 사용 중이면 로그인 시작이 거부됩니다.

한키는 지원되지 않는 입력창에서 전체 텍스트 선택이나 전체 삭제를 시도하지 않습니다.
클립보드 붙여넣기 호환 모드는 기본 OFF이며 사용자가 켜도 민감·제외·보호 대상에서는 동작하지 않습니다.
실제 PC방과 문제 게임에서 0.2.1-rc.1을 아직 재검증하지 않았습니다.
