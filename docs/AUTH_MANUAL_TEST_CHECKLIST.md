자동화된 실제 Google 로그인은 불가능하므로, 아래 항목은 반드시 사람이 직접 실행해야 합니다.

## 사전 준비

- [ ] `Hanki.exe`와 같은 폴더에 `hanki.auth.config.json` 파일을 생성했다 (템플릿:
      `src\Hanki.App\hanki.auth.config.json.example`). `supabaseUrl`, `supabasePublishableKey`는
      Yulbyte 웹사이트와 동일한 Supabase 프로젝트 값을 사용한다.
- [ ] Supabase 대시보드(Authentication → URL Configuration → Redirect URLs)에
      `http://127.0.0.1:43289/auth/callback` 이(가) 등록되어 있다.
- [ ] Google Cloud Console의 OAuth 클라이언트(Supabase가 사용하는 것과 동일한 클라이언트)의
      승인된 리디렉션 URI 목록에는 Supabase 콜백 URL만 있으면 되며, 이 앱의 루프백 주소를
      Google 쪽에 별도로 등록할 필요는 없다 (Supabase가 중개).

## 로그인 흐름

- [ ] **최초 로그인**: "계정" 탭에서 "Google로 로그인" 클릭 → 기본 브라우저가 열리고 Google
      로그인 화면이 표시된다. 로그인 완료 후 브라우저에
      "로그인이 완료되었습니다. 이 창을 닫아도 됩니다." 가 표시되고, 앱으로 돌아오면 이름/이메일/
      아바타가 표시된다.
- [ ] **이미 브라우저에 로그인된 상태**: 브라우저에 Google 세션이 이미 있는 상태에서 로그인 →
      계정 선택 화면이 바로 뜨거나 자동으로 로그인되고, 앱에 정상적으로 반영된다.
- [ ] **계정 선택**: Google 계정이 여러 개인 브라우저에서 로그인 → 원하는 계정을 선택하면 그
      계정 정보(이메일)가 앱에 정확히 표시된다.
- [ ] **로그인 취소**: 로그인 진행 중 앱의 "취소" 버튼 클릭 → 브라우저 탭은 남아있어도 무방하나,
      앱은 "로그인이 취소되었습니다." 메시지와 함께 로그아웃 상태로 돌아가고, 로그인 버튼이 다시
      활성화된다.
- [ ] **브라우저 창 닫기**: Google 로그인 화면에서 브라우저 탭/창을 그냥 닫음 → 앱은 결국(최대
      5분 이내) "로그인 시간이 초과되었습니다. 다시 시도해주세요." 를 표시하거나, 취소 버튼으로
      직접 중단할 수 있다. 앱이 멈추거나 응답 없음 상태가 되지 않는다.
- [ ] **인터넷 연결 해제**: 로그인 버튼 클릭 직후 네트워크를 끔 → 코드 교환 단계에서 실패하며
      "인터넷 연결을 확인한 뒤 다시 시도해주세요." 가 표시된다. 앱이 죽지 않는다.
- [ ] **콜백 시간초과**: 브라우저를 열어둔 채 5분 이상 아무 것도 하지 않음 → "로그인 시간이
      초과되었습니다. 다시 시도해주세요." 표시. 이후 포트(43289)가 다른 로그인 시도에서 다시
      정상적으로 사용 가능하다 (재시도 시 오류 없음).
- [ ] **잘못된 state**: (개발자 전용) 콜백 URL의 `state` 쿼리 파라미터 값을 브라우저 주소창에서
      직접 변조한 뒤 접속 → "로그인 요청을 확인할 수 없습니다. 다시 로그인해주세요." 표시되고
      토큰 교환이 발생하지 않는다(네트워크 탭/로그로 확인 가능하면 확인).

## 세션 유지 및 재시작

- [ ] **앱 재시작 후 세션 유지**: 로그인 성공 → 앱을 완전히 종료 후 다시 실행 → 별도 로그인 없이
      로그인 상태(이름/이메일)가 그대로 복원된다.
- [ ] **완전 종료 후 재실행**: 트레이 메뉴 "완전히 종료"로 종료 → 재실행 → 로그인 상태 유지,
      기존 단축어도 모두 그대로 있다.
- [ ] **로그아웃**: "로그아웃" 버튼 클릭 → 즉시 로그아웃 상태(설명 문구 + "Google로 로그인" 버튼)로
      바뀐다.
- [ ] **로그아웃 후 재실행**: 로그아웃 후 앱 재시작 → 로그인 상태로 자동 복원되지 않고 로그아웃
      상태로 시작한다.
- [ ] **Access Token 만료**: (시스템 시계를 앞당기거나 장시간 대기) access token 만료 임박 시
      앱 시작 시점에 자동으로 refresh가 일어나고, 사용자는 별도 조작 없이 로그인 상태를 유지한다.
- [ ] **Refresh Token 만료**: Supabase 대시보드에서 해당 사용자의 세션/refresh token을 강제로
      무효화한 뒤 앱 재시작 → "저장된 로그인 정보가 만료되었습니다. 다시 로그인해주세요." 문구가
      보이고 로그아웃 상태로 전환된다. 앱이 멈추거나 반복 재시도하지 않는다.
- [ ] **저장 세션 손상**: `%LocalAppData%\Yulbyte\Hanki\auth.session` 파일을 임의의 바이트로
      덮어쓴 뒤 앱 실행 → 앱이 죽지 않고 로그아웃 상태로 정상 시작한다.
- [ ] **설정 누락**: `hanki.auth.config.json` 파일을 삭제(또는 이름 변경)한 뒤 앱 실행 → 앱은
      정상적으로 실행되고, "Google로 로그인" 버튼은 비활성화되며 툴팁으로
      "로그인 설정이 없습니다." 가 표시된다. 다른 기능(단축어 등)은 모두 정상 동작한다.
