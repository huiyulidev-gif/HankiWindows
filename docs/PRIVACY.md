# 한키 0.2.0-dev 개인정보 안내

한키의 단축어 기능은 로컬 우선으로 동작합니다. Google 로그인은 사용자가 명시적으로
선택할 때만 네트워크를 사용하며, 현재 단축어 클라우드 동기화는 제공하지 않습니다.

## 수집하거나 전송하지 않는 정보

- 단축어, 변환 문장, 사용 횟수와 앱 설정을 서버로 전송하지 않습니다.
- 사용자가 입력한 전체 키 기록을 저장하지 않습니다.
- 입력한 문장과 변환된 문장을 서버로 전송하지 않습니다.
- 클립보드를 읽거나 저장하지 않습니다.
- 원격 분석 및 광고 SDK를 포함하지 않습니다.

## 로컬에 저장하는 정보

`%LocalAppData%\Yulbyte\Hanki\hanki.db`에 사용자가 만든 단축어, 즐겨찾기, 사용 횟수,
최근 사용 시각, 앱 설정만 저장합니다.

오류 로그에는 발생 시각, 예외 종류, 오류가 발생한 기능 위치만 기록합니다.
실제 입력 내용, 단축어 텍스트, 변환 문장, 클립보드, 비밀번호, 토큰, 이메일은 기록하지 않습니다.

## 선택적 Google 로그인

로그인을 선택하면 Supabase Auth를 통해 Google 계정의 이메일, 이름, 프로필 이미지 URL을
받아 계정 탭에 표시합니다. Access Token과 Refresh Token은 별도 `auth.session` 파일에
Windows DPAPI `CurrentUser` 범위로 암호화해 저장하므로 다른 Windows 계정과 공유되지
않습니다. 로그아웃과 복구할 수 없는 refresh 실패 시 이 파일을 삭제합니다.

로그인하지 않아도 단축어 추가·수정·삭제, 변환, 백업·복원 등 로컬 기능을 사용할 수
있습니다. 현재 웹 계정이나 다른 PC로 단축어를 보내지 않습니다. 서비스 탈퇴 및 서버의
계정 데이터 삭제 절차는 공개 출시 전에 Yulbyte 정책 확인이 필요합니다.

## 입력 감지 방식

한키는 저수준 키보드 훅으로 Space 키업만 감지합니다. 모든 키를 장시간 버퍼링하지 않습니다.
Space 입력 후 Windows UI Automation을 이용해 현재 포커스된 일반 텍스트 요소를 확인하고,
커서 앞에서 단축어 판정에 필요한 짧은 범위만 메모리에서 일시적으로 읽습니다.
일치하는 경우 해당 범위만 선택하고 Win32 `SendInput`의 Unicode 입력으로 교체합니다.

임시 문자열과 입력 상태는 파일에 저장하지 않으며 앱 종료 시 유지하지 않습니다.

## 민감한 입력창

Windows UI Automation의 `IsPassword` 속성이 true인 요소에서는 텍스트를 읽거나 변환하지 않습니다.
Windows 보안 화면, UAC 보안 데스크톱, 잠금 화면, 안전한 입력 영역인지 판별할 수 없는 요소에서도 건너뜁니다.
