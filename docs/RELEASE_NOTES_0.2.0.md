# 한키 Windows 0.2.0

한키는 Windows에서 반복 입력을 줄이는 로컬 단축어 생산성 앱입니다.

## 주요 기능

- Yulbyte 공식 로고와 브랜드
- Windows 앱 내 Google 로그인 및 Google 계정 선택
- PKCE Authorization Code 인증과 DPAPI 로컬 세션 보호
- 단일 인스턴스, 트레이 숨김/복원, 창 복원
- 계정 탭과 로그인 상태 UI
- 설치형 및 Portable 배포
- 기존 단축어와 설정 보존
- 입력 보호, 제외 앱·사이트, 자동 시작

## 제한

- 클라우드 단축어 동기화는 아직 지원되지 않습니다.
- 단축어는 현재 PC 로컬에 저장됩니다.
- 설치 파일은 코드 서명되지 않아 SmartScreen에서 알 수 없는 게시자로 표시될 수 있습니다.
- Windows 10/11만 지원하며 macOS·모바일은 지원하지 않습니다.
