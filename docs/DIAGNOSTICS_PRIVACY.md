# 호환성 진단 개인정보 보호

한키 0.2.1 진단은 현장 실패 단계를 구분하기 위한 로컬 기능이다.
원격 분석 서버로 전송하지 않으며 사용자가 **진단 ZIP 내보내기**를 눌렀을
때만 파일을 만든다.

## 메모리 보관 범위

- 최근 이벤트 최대 200개
- 앱 실행 중인 동안만 유지
- 순환 큐가 가득 차면 가장 오래된 이벤트부터 제거
- 사용자 단축어와 입력 문맥 원문은 이벤트 모델에 필드가 없음

## 포함하는 정보

- UTC 시각과 이벤트 순번
- 한키 버전, Windows 설명, 프로세스 아키텍처
- 한키와 대상 프로세스의 무결성 수준
- 대상 프로세스 실행 파일명(전체 경로 제외)
- 후크 등록 여부, 전용 스레드 여부, 숫자형 핸들·스레드 ID
- 등록·마지막 콜백·마지막 종결자·성공·실패 시각
- 키보드 레이아웃 식별자
- IME 열림/조합 여부, Caps Lock, Num Lock, Windows 세션 번호
- Space/Enter/숫자패드 Enter/Tab 중 종결자 종류
- 삭제·변환문·종결자 단계의 요청/성공 입력 이벤트 수
- 열거형 차단 사유, 입력 문맥 상태, 고정 결과 코드
- 단축어 원문 대신 UUID 형식의 로컬 단축어 ID
- 사용자가 직접 선택한 외부 앱 수동 테스트 상태

## 포함하지 않는 정보

- 사용자가 누른 실제 문자와 전체 키 입력
- 단축어 원문
- 변환문 원문과 길이
- 문서·메시지·주소창 전체 내용
- 창 제목
- 클립보드 내용과 형식별 실제 데이터
- 사용자 이름, 이메일, 전화번호, 비밀번호
- 전체 파일 경로와 사용자 프로필 경로
- 인증 토큰, OAuth 코드, 세션 파일
- 브라우저 전체 URL 또는 제외 사이트 도메인

프로세스 파일명은 앱 종류를 구분하기 위해 허용하지만 디렉터리는
`Path.GetFileName`으로 제거한다. 단축어 ID는 UUID 형식이 아니면 버린다.
오류 메시지 전체를 넣지 않고 예외 형식 또는 고정 오류 코드만 사용한다.

## ZIP 구성

내보낸 ZIP에는 다음 세 파일만 있다.

- `hanki-compatibility-diagnostics.json`
- `hanki-compatibility-diagnostics.txt`
- `PRIVACY.txt`

JSON과 TXT는 같은 스냅샷의 기계 판독/사람 판독 표현이다. ZIP 경로나 사용자
선택 파일명은 보고서 본문에 넣지 않는다.

## 클립보드 호환 모드

클립보드 모드는 기본 OFF다. 켠 경우 변환문은 붙여넣기 동안만 Windows
클립보드에 존재할 수 있다.

- 진단 이벤트에는 내용이나 길이를 넣지 않는다.
- 비밀번호·제외 앱·제외 사이트·보호 대상에서는 시작하지 않는다.
- 기존 데이터 객체는 메모리에만 보관한다.
- 시퀀스 번호가 바뀌면 사용자의 새 클립보드를 강제로 덮어쓰지 않는다.
- 복원 성공/건너뜀/실패 상태만 기록한다.

이미지·파일 목록 등 복합 형식은 WPF 데이터 객체로 가능한 범위에서
복원한다. 운영체제나 원본 앱이 지연 렌더링 데이터를 더 이상 제공하지 않으면
완전 복원이 불가능할 수 있으며 그 경우 실패 상태를 표시한다.

## 자가 테스트

후크 자가 테스트는 제한 시간 안에 입력 이벤트가 도착했는지만 확인한다.
누른 키의 값, 가상 키 코드, 스캔 코드, 문자는 보고서에 넣지 않는다.

내부 변환 테스트의 고정 단축어와 변환문은 소스에 정의된 공개 테스트
문자열이며 데이터베이스에 저장하지 않는다. 진단에는 고정 UUID와 성공/실패
상태만 남는다.

## 자동 검증

자동 테스트는 다음을 확인한다.

- 260개 이벤트를 넣어도 최근 200개만 유지
- 프로세스 전체 경로 제거
- UUID가 아닌 단축어 식별자 제거
- ZIP의 정확한 엔트리 세 개
- JSON/TXT에 단축어·변환문·클립보드·창 제목 필드 없음
- 테스트 데이터 폴더와 현재 사용자 이름 미포함
- 클립보드 정상 복원과 동시 사용자 변경 보존

현장 전달 전에는 ZIP 압축을 직접 열어 문서·계정 정보가 없는지 한 번 더
확인하는 것을 권장한다.
