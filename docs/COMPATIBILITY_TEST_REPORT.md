`node_repl exec context not found`를 반환했다. 따라서 로컬 WPF 창은 Windows
UI Automation으로 탭 존재와 `변환 상태: 켜짐` 표시를 확인하고 `PrintWindow`
결과를 육안 검사했다. 격리 인스턴스는 종료 코드 0으로 자동 종료됐다.

## 관리자/UIPI

무결성 수준 판정과 비교 단위 테스트는 PASS다. 사용자 직접 실행 스크립트와
앱 내 관리자 재시작 버튼을 제공하지만, 자동 UAC 승인이나 보안 정책 우회는
수행하지 않았다. 실제 관리자 메모장 비교 결과는 미검증이다.

## 판정

코드 수준에서 확인된 0.2.0의 Enter/Tab 미구현, 후크 생존 상태 부재,
조용한 UIA 실패, 단계별 `SendInput` 미분리는 수정됐다. 그러나 실제 PC방과
문제 게임에서 같은 증상이 해결됐다는 증거는 아직 없다. RC는 현장 원인
분류와 재검증을 위한 후보이며 정식 0.2.1이 아니다.
