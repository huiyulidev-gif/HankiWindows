# Google 계정 선택 수동 확인 — 0.2.0-rc.2

자동 인증 입력은 하지 않습니다. 기존 설치 앱과 사용자 DB를 보호하려면 격리 Portable 실행 스크립트를 사용하세요.

## 실행

1. 기존 한키 창이 열려 있으면 한키의 정상 종료 기능으로 완전히 종료합니다.
2. 다음 스크립트를 실행합니다.
   `C:\Users\MSI\Desktop\개발\HankiWindows\dist-rc\0.2.0-rc.2\Run-Account-Picker-Test.ps1`
3. 격리 앱의 계정 탭에서 `Google로 로그인`을 누릅니다.
4. Chrome에서 기존 로그인 세션이 있어도 계정 목록 또는 `다른 계정 사용`이 표시되는지 확인합니다.
5. 계정을 선택하거나 비밀번호/MFA를 입력하지 않아도 됩니다.
6. 앱의 취소 기능으로 돌아오거나 앱을 정상 종료합니다.
7. listener와 `127.0.0.1:43289`가 종료되었는지 확인합니다.

스크립트는 `HANKI_DATA_DIRECTORY`와 격리 instance namespace를 사용하고, 기존 Hanki 프로세스를 임의로 종료하지 않습니다. 충돌하는 listener가 있으면 실행하지 않고 안내만 합니다.

## PASS 기준

- Chrome에 로그인된 계정이 있어도 계정 선택 화면이 표시됨
- 계정 목록 또는 `다른 계정 사용`이 표시됨
- 특정 계정으로 자동 확정되지 않음
- 취소/종료 후 listener와 포트가 정리됨
- 실제 사용자 DB·세션에 변경이 없음

## FAIL 기준

- 기존 Chrome 계정으로 즉시 인증 완료
- 계정 선택 화면 없음
- 특정 계정이 자동 고정됨
- 취소 후 listener 또는 포트가 남음
