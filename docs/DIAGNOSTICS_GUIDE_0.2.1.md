# 한키 0.2.1 진단 가이드

## 빠른 순서

1. Portable ZIP을 새 폴더에 압축 해제한다.
2. `Hanki.exe`를 실행한다.
3. **호환성 진단** 탭을 연다.
4. **키 입력 감지 자가 테스트**를 누르고 아무 키나 한 번 누른다.
5. **임시 테스트 준비**를 누른 뒤 `;hankitest`와 Space를 입력한다.
6. 일반 메모장과 문제가 발생한 앱을 각각 시험한다.
7. 외부 프로그램 결과를 화면에서 선택한다.
8. **진단 ZIP 내보내기**를 누른다.
9. ZIP을 열어 개인 문서·계정 정보가 없는지 확인한다.
10. 한키를 트레이 메뉴에서 완전히 종료한다.

## 결과 분류

- **키 감지 실패**: 후크 등록·전용 스레드·최근 콜백을 확인한다. 보안 제품
  차단을 아직 확정할 수 없다.
- **내부 테스트 성공, 외부 실패**: 대상 무결성·입력 문맥·제외/민감 판정과
  단계별 주입 수를 확인한다.
- **삭제만 성공**: Ctrl+Z 복구 가능성을 확인하고 같은 입력을 반복하지 않는다.
- **대상 권한이 더 높음**: UIPI 가능성이 높다. 관리자 재시작은 필요한
  경우에만 사용자가 직접 누른다.
- **지원하지 않는 입력창**: UI Automation 텍스트 문맥이 없어 안전한 단축어
  판정을 할 수 없다.

## 보내도 되는 파일

한키가 만든 `Hanki-diagnostics-날짜-시간.zip`만 보낸다. ZIP에는
JSON·TXT·개인정보 안내가 있다.

다음은 보내지 않는다.

- 단축어/변환문 원문
- 문서나 채팅 화면 캡처
- 비밀번호·이메일·전화번호
- 별도로 복사한 클립보드 내용
- 사용자 프로필 전체 경로

## 주의

한키는 게임 보안 모듈과 PC방 보안 정책을 우회하지 않습니다. 이 릴리스가
특정 PC방 문제를 해결했는지는 현장 재검증 뒤에만 판정할 수 있습니다.
